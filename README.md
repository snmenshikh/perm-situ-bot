# 🤖 perm_situ_bot - чат-бот Сетевого ИТ-Университета (СИТУ)

`perm_situ_bot` - серверный чат-бот для мессенджера **MAX**,
предназначенный для автоматизированного интеллектуального взаимодействия 
с абитуриентами и слушателями **Сетевого ИТ-Университета (СИТУ)** (Пермский край).
Бот предоставляет справочную информацию, обеспечивает навигацию по обучающим программам, 
позволяет получать сведения о заявлениях и вести диалог с AI-агентом 
(интерактивным помощником Ситушей).

## 🎯 Назначение

-   Первичное информирование об обучении в СИТУ
-   Ответы на часто задаваемые вопросы
-   Поиск заявлений слушателей по номеру телефона
-   Диалог с AI-агентом (интерактивный помощник Ситуша) по тематикам обучения
-   Снижение нагрузки на команду Университета

## 🧩 Основные сценарии работы

-   FAQ («Частые вопросы»)
-   Поиск информации о заявлениях слушателей СИТУ через внешний REST API
-   Получение информации о ВУЗах-участниках проекта
-   Диалог с интерактивным помощником Ситушей (GigaChat)

## 🧠 Использование LLM

-   Поиск ответа в базе знаний СИТУ
-   При отсутствии релевантного ответа - обращение к AI-агенту
-   Использование строгого системного промпта
-   Контроль нерелевантности, задействование стоп-слова
-   Состояния нарушений хранятся индивидуально для каждого пользователя
-   Блокировка обращения к AI-агенту при двух и более нарушениях 
    (общение, выходящее за темы обучения в СИТУ)

## 🔐 Безопасность и устойчивость

-   Безопасное выполнение запросов
-   Whitelist ключевых слов
-   Защита от нерелевантных запросов к LLM
-   Ограничение тематики диалога с AI-агентом
-   Retry и backoff для внешних API
-   "Прогрев" API при старте чат-бота для предотвращения DNS cold-start
-   Сброс состояний при перезапуске чат-бота

## 🛠 Стек технологий

-   Python 3.8+
-   MAX Bot API
-   REST / JSON
-   GigaChat API
-   Docker, Portainer
-   requests, typing
